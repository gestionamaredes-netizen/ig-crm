# @fabbenok — Presentación del perfil

**Fecha:** 2026-07-31
**Fuente:** captura del perfil al 31/07 (68 publicaciones, 7.228 seguidores, 65,5 mil visualizaciones en 30 días)

## El problema de la bio actual

```
Productor cinematográfico
Papá de Almen❤️
@scs__play 🇪🇸
@jeremiaszarate_ 👁
@iniciativaglobalok📊
@ama.blur 🚀
@2115films 🎬
@huelga.afectiva 🖌
```

Seis menciones seguidas sin etiqueta. Quien cae al perfil por primera vez no sabe cuál
es la agencia, cuál es la productora y cuál es el proyecto personal: son seis arrobas
con un emoji cada una. Además el límite de Instagram son 150 caracteres, así que cada
mención que se queda le come lugar a decir algo.

La regla que ordena todo: **una etiqueta por mención**. Que la bio se lea como un
índice, no como una lista de seguidos.

## Opción recomendada

```
Productor cinematográfico · Buenos Aires
Papá de Almen ❤️
Agencia: @iniciativaglobalok
Cine: @2115films · @ama.blur
Poemas: @huelga.afectiva
```

148 caracteres. Entra justo.

Qué queda afuera y por qué: @scs__play y @jeremiaszarate_ son talentos/proyectos que
representás, no cosas que te definen a vos. Van mejor en un highlight propio
("Talentos" o "Roster") o en el link de Netlify, donde no compiten por los 150
caracteres. Si uno de los dos es innegociable, el lugar sale de fusionar la línea de
cine: `Cine: @2115films` y @ama.blur pasa al highlight de Rodajes que ya existe.

## Variante más personal

```
Hago cine y campañas. A veces poemas.
Papá de Almen ❤️
@iniciativaglobalok · @2115films
@ama.blur · @huelga.afectiva
```

134 caracteres. Pierde las etiquetas por mención pero gana una primera línea que suena
a persona y le da entrada a Huelga Afectiva desde la presentación misma. Sirve si la
idea es que el perfil personal empuje el relanzamiento literario.

## Variante hub (agregada 2026-07-31, a pedido de Fabricio)

La web fabbenok.netlify.app pasa a ser el directorio completo y la bio se descarga de
arrobas. Solo quedan las dos cuentas que definen a la persona; el resto vive en la
página, donde además cada proyecto puede llevar una línea de descripción.

```
Productor cinematográfico
Papá de Almen ❤️
Dirijo @iniciativaglobalok
Escribo en @huelga.afectiva
Todos mis proyectos acá 👇
```

123 caracteres. Condición para que funcione: la página tiene que tener una sección de
links con las ocho cuentas y una línea por cada una (agencia, productoras, espacio
literario, talentos, e-commerce). Sacar arrobas de la bio no pierde tráfico si el link
lo absorbe — y el clic al link se mide desde el panel profesional de Instagram, cosa
que las menciones no permiten.

> Nota: no se pudo verificar el contenido actual de fabbenok.netlify.app desde este
> entorno (la política de red bloquea el dominio). Revisar que la sección de links
> exista antes de cambiar la bio.

## Variante corta

```
Productor cinematográfico
Papá de Almen ❤️
Dirijo @iniciativaglobalok
Escribo en @huelga.afectiva
fabbenok.netlify.app
```

Para cuando el link de Netlify pase a ser el hub de todo (ahí sí caben las ocho
cuentas con descripción). Es la bio más limpia de las tres, pero depende de que la
página esté al día.

## Decisiones que no toma este documento

- Cuál de las tres versiones va. Las tres respetan el límite de caracteres; la
  elección es de Fabricio.
- Si @scs__play y @jeremiaszarate_ se mudan a un highlight, hay que crearlo antes de
  cambiar la bio para no dejarlos sin puerta de entrada.
