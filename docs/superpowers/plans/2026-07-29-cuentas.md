# Sector Cuentas — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development. Steps use checkbox (`- [ ]`) syntax.

**Goal:** Un sector "Cuentas" (independiente): cada cuenta tiene un **titular** (que suele ser emisor/receptor), sus **CBU/alias en pesos y en dólares**, y muestra el **movimiento** (volumen USD y operaciones como emisor y como receptor) que sale de matchear el titular con el emisor/receptor de las operaciones.

**Architecture:** Tabla `cuentas` nueva, capa de datos, server actions CRUD, y página `/cambio/cuentas`. El movimiento por cuenta se DERIVA reusando `rankingPersonas(operaciones)`, matcheando por nombre normalizado. Registro aislado: no toca el cálculo. Espeja el patrón de celulares/runners.

**Tech Stack:** Next.js 16, React 19, TypeScript, Supabase, Vitest.

## Global Constraints

- Empresa en SQL: `where c.name ilike '%gestiones%ma%'`. SQL idempotente `web/lib/db/sql/2026-07-29-cuentas.sql`, corrido a mano. Proyecto `zjetaihjddoxxvrpzwsb`.
- Tabla: `id uuid pk default gen_random_uuid()`, `company_id uuid not null references companies(id) on delete cascade`, `created_at timestamptz default now()`. RLS `for all to authenticated using (true) with check (true)`.
- Server actions: `type ResultadoAlta = { ok: true } | { ok: false; error: string }`; `revalidatePath("/cambio/cuentas")` aislado; log `[cambio]`; SIN candado; validar antes de `createClient()`.
- Lecturas por `createClient()` de `@/lib/supabase/server`; `LIMITE = 10000` + `console.error` si trunca; mappers snake→camel.
- **Movimiento**: se reusa `rankingPersonas(operaciones)` de `@/lib/cambio/reportes` (devuelve `{ persona, comoEmisor, comoReceptor, volumen, operaciones }`); se matchea el `titular` con `persona` por nombre normalizado (trim + lowercase, igual que rankingPersonas).
- **MOLDE:** el sector de celulares es el patrón. Referencias: `lib/cambio/celulares.ts`, `celulares-datos.ts`, `app/(app)/cambio/celulares-actions.ts`, `components/cambio/celular-forms.tsx`, `components/cambio/celulares-lista.tsx`, `app/(app)/cambio/celulares/page.tsx`.
- Estilos inline, CSS variables, acento dorado, mobile-first (`.ops-cards`/`.ops-tabla`, `.campo-fila`, `.cambio-modal`). NO pasar funciones de server a client components.

  dni           text not null default '',
