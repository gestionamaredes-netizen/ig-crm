EL SET

Sobrio y premium. Dos butacas, luz direccional y fondo profundo: la escena es la invitada.

Plano de entrevista clásico con dos cerrados y un general. Edición limpia, sin efectismo. Este formato no necesita movimiento de cámara: necesita que se entienda lo que dice.
