EN VIVO O GRABADO

Es el único de la grilla que no necesita salir en vivo. Si se graba antes y se emite a las 16:30, pasan dos cosas buenas: se pueden hacer dos episodios en la misma jornada con el mismo armado, y el piso queda libre toda la tarde para armar El Motivo, que entra a las 18:00.

Si sale en vivo, entre las 17:30 y las 18:00 hay media hora para desarmar este set y armar el de El Motivo, y El Motivo necesita cuarenta y cinco minutos.

LA REGLA DEL FORMATO

Nada sale sin lo concreto: cada historia deja al menos un dato o una decisión replicable. Es un ciclo de material de trabajo, no de vidrieras de éxito.

Si al escuchar el episodio entero no hay nada que anotar, se vuelve a grabar o se corta distinto.
