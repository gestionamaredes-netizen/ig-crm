# Guías del panel

Imágenes paso a paso, con capturas reales del sistema anotadas. Están pensadas
para mandarse por WhatsApp: una por mensaje, en orden.

- **`acceso/como-entrar.png`** — la de entrar al panel, para mandarle a cualquiera
  que empieza a usarlo. Muestra el link, dónde va la clave y qué abre cada una.
  **No muestra ninguna clave**: la clave se pasa aparte, nunca en la imagen.
- **`administracion/`** — las diez de quien maneja el negocio: entrar, cargar una
  compra, confirmarla, poner precios, dar de alta un comercio, cargar un pedido,
  entregar y cobrar, la caja, cómo viene el mes y la pantalla del depósito.
- **`comercio/`** — las tres para mandarle a cada cliente cuando se le pasa su
  link de acceso.

Las capturas salen del sistema andando, así que **envejecen**: si cambia una
pantalla, hay que volver a generarlas para que la guía no mienta.
