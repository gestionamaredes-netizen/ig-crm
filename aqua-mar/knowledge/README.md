# Base de conocimiento de Aqua IA

Fuente editable de lo que el asistente puede responder. El contenido
operativo que usa el código vive en `src/ai/knowledge.ts`: al editar un
archivo de esta carpeta, actualizar también ese módulo (son textos cortos,
la sincronización es manual y a propósito: obliga a revisar cada cambio).

Regla: si un dato no está acá, Aqua IA no lo responde — deriva al equipo.
