# Actualización de la web e imágenes

## Quién publica
Solo usuarios autorizados modifican productos, precios, stock, cobertura,
contactos, imágenes, condiciones, textos legales y analítica.

## Checklist antes de publicar
[ ] Revisión visual [ ] Revisión de contenido [ ] Revisión mobile
[ ] Enlaces verificados [ ] `npm run typecheck` y `npm run build` OK
[ ] Deploy Preview de Netlify revisado [ ] Aprobación [ ] Publicación

## Protocolo de imágenes
Carpetas: `public/products/` (originales `*-original.jpg`),
`public/branding/`, `public/og/`.
Reglas: los originales NO se sobrescriben · las versiones optimizadas
conservan el producto exactamente · no modificar logos, etiquetas ni
colores · no deformar · no aplicar filtros que cambien la apariencia
real · nunca reemplazar fotos por renders o imágenes generadas ·
mantener copias de respaldo (Git).
